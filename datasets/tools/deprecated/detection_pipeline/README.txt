datasets/tools/deprecated/detection_pipeline/
=============================================

This folder contains dataset tools from the earlier bounding-box detection experiments.
They were replaced by the current segmentation pipeline and are retained only as development records.

- create_fracatlas_hard_negative_review.py
- create_fracatlas_stage_1_list.py
- create_fracatlas_stage_2_list.py
- create_fracatlas_stage_3_list.py
- create_fracatlas_stage_3_crop_review.py
- mine_fracatlas_hard_negatives.py
- prepare_fracatlas_stage_3_crops.py

These scripts are not used to train or evaluate the current FractureVision
release model.
